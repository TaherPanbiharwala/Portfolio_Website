Cardiac Arrhythmia

Arrhythmia Detection & Classification

Healthcare AI

This project leverages supervised machine learning to analyze ECG and physiological data for detecting and classifying cardiac arrhythmias. By processing large datasets from the UCI Machine Learning Repository, it aims to reduce human error in diagnosis.

Two models were developed: Model 1 for binary detection (normal vs. arrhythmia) and Model 2 for multi-class classification of specific arrhythmia types. Techniques such as data cleaning, feature selection with Boruta, and various algorithms—including Random Forest, XGBoost, SVM, and Neural Networks—were employed.

The Random Forest model achieved an accuracy of 87% for detection, while XGBoost delivered robust performance in classifying arrhythmia types. This work demonstrates how machine learning can support clinical decisions by improving diagnostic accuracy.

Check it out on GitHub.

Action Classifier

Action Classifier using CNN and Transfer Learning

Deep Learning for Action Recognition

This project implements an action classifier that leverages CNNs with transfer learning using the pre-trained VGG16 model. It classifies human actions into two categories: Running and Walking, utilizing Python, TensorFlow, and Keras.

Key Features: Efficient dataset splitting, data augmentation with ImageDataGenerator, robust feature extraction via VGG16, and hyperparameter tuning using Keras Tuner's RandomSearch. The model is capable of predicting actions from both images and video streams with OpenCV.

Training achieved a best validation accuracy of 83.59% and a test accuracy of 86.04% with optimal parameters including 1 convolution block, 96 filters (3x3 kernel), 128 dense units, and a dropout rate of 0.2 using RMSProp.

Check it out on GitHub.

CrazyWorld-VR

Artistic VR Experience

This Unity VR project, inspired by Picasso's art style, creates an engaging environment featuring a character with a distinctive limping effect. Using inverse kinematics and cosine functions, the project offers a unique and artistic virtual reality experience.

Installation: Clone or download the repository, open the CrazyWorld-VR folder in Unity, and follow the on-screen instructions to run the project.

Deepfake Detection with Meso4

Media Authentication
